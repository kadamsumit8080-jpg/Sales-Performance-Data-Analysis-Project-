# Ecommerce Sales Dashboard

## Project Overview
This project analyzes ecommerce sales performance using Power BI.  
Key highlights:
- Maharashtra leads in revenue
- Clothing contributes 63% of total quantity
- GitHub repository contains all project files

---

## Business Problem
The company needs to optimize:
- Sales performance
- Customer engagement
- Profitability

### Challenges
- Regional sales gaps (Delhi & UP underperforming)
- Loss-making sub-categories (Sarees, Bookcases)
- High dependency on COD payments (44%)
- Seasonal profit dips (April–June, September)

---

## Steps (Project Script)
1. Imported and cleaned data from CSV files  
2. Built relationships between **Orders** and **Details** tables  
3. Created DAX measures for KPIs:
   - Amount
   - Profit
   - Quantity
   - Average Order Value (AOV)  
4. Designed visuals:
   - Sales by State
   - Payment Mode distribution
   - Monthly Profit trend
   - Customer-wise sales
   - Category & Sub-category analysis  
5. Added slicers for interactivity

---

## Key Insights
- Maharashtra leads in revenue  
- Clothing contributes 63% of quantity but faces profit issues  
- COD dominates payment modes  
- Printers & Accessories are profitable, while Sarees & Bookcases show losses  

---

## Recommendations
- Focus on profitable sub-categories  
- Revisit pricing for Sarees & Bookcases  
- Encourage digital payments (UPI, Credit Card)  
- Plan campaigns for low-profit months  

---

## How to Use
1. Open **MonthlySalesGrowth.pbix** in Power BI  
2. Use slicers to filter by:
   - State
   - Category
   - Payment mode
   - Date  
3. Explore insights interactively
